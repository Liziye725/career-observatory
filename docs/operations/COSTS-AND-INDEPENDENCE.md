# 免费与独立运行边界

代码、SQLite、本地Node和自有机器定时运行不要求付费服务，但机器、电力和维护不是零成本承诺。Gmail API仍受额度与OAuth政策影响。GitHub私有仓库/CI和云存储均需按账户当前套餐核验，本文不声称固定免费额度。

独立运行至少需要：常驻执行主机、邮箱授权、可获取网页/PDF的研究执行器、模型或本地推理资源、持久数据库，以及对外网站的认证和托管。ChatGPT现有连接器/自动任务不自动授权给GitHub Actions。

可以本地模型+本地存储降低外部API费用，但质量、显存、搜索服务和维护成本需评估。当前仓库刻意未硬绑定收费模型，不能据此宣称零费用全自动研究已经实现。
